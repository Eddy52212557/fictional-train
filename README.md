# IA App Builder

Una aplicación de inteligencia artificial que permite a los usuarios crear y entrenar sus propios modelos de IA sin necesidad de conocimientos avanzados en programación.

## Objetivo

Facilitar la creación de aplicaciones de inteligencia artificial mediante una interfaz intuitiva y herramientas accesibles.

## Características Principales

- ✔ Interfaz de arrastrar y soltar para construir modelos de IA.
- ✔ Plantillas predefinidas para diferentes tipos de aplicaciones de IA.
- ✔ Carga de datos y entrenamiento de modelos personalizados.
- ✔ Evaluación del rendimiento de los modelos.
- ✔ Integración sencilla en aplicaciones web y móviles.

## Tecnologías Utilizadas

- **Frontend**: React
- **Backend**: Node.js
- **IA**: TensorFlow.js
